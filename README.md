# Weather App

A simple, responsive weather app that shows real-time weather data for any city, built using HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Press Enter or click Search to get results
- Displays temperature, weather description, humidity, and a weather icon
- Loads Nairobi's weather by default on page load
- Handles errors gracefully (invalid city, API issues)

## Built With
- HTML5
- CSS3 (Flexbox)
- JavaScript (vanilla, no frameworks)
- [OpenWeatherMap API](https://openweathermap.org/api) — for live weather data
